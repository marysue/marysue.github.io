How do you install and run a new vue project?

  1. sudo npm install -g @vue/cli
  2. vue create my-app
  3. cd my-app
  4. npm run serve or yarn serve

What are the two styles of writing vue?

  1. Options:
    • Options is an object: Uses Data, Method and Mounted keys
    • No <script> tag surrounds Options. Just export the options object
    • Good for smaller apps and class based apps -- can use this component instance
  2. Composition
    • Uses <script> tag for javascript code
    • use <script setup> so you do not have to explicitly export vars

How do you create a Vue3 app?

  1. In App.js:
    import { createApp } from 'vue'; const app = createApp({ data() { return { count: 0 } } }); app.mount('#app')
  2. In the markup section:
    <div id="app">
    <button @click="count++">{{ count }} </button>
    </div>
  3. Then, after all setup is done, mount the application, using a "container" arg or an element id:
    app.mount('#app');

What is the explicit way to implement two way binding on an input element?

use :value="varName" @input="inputFunctionName" in your input element;

<script setup>
import { ref } from 'vue'

const varName = ref('')

function inputFunctionName(e) {
    varName.value = e.target.value
}
</script>

<template>
    <input :value="varName" @input="inputFunctionName" placeholder="Type here">
    <p>{{ varName }}</p>
</template>

What is the shorthand for two way binding on your input element?

< input v-model="text">

There is no longer the need for the @input="onInput" function or :value="text" as v-model will directly change the value of your variable "text".value using v-model="text"

Before:

%lt;script setup>
    import { ref } from 'vue'
    
    const text = ref('')
    
   function onInput(e) { 
      text.value = e.target.value
   }
    </script>
    
    <template>
      <input :value="text" @input="onInput" placeholder="Type here">
      <p>{{ text }}</p>
    </template>

After, using v-model

<script setup>
    import { ref } from 'vue'
    
    const text = ref('')
    </script>
    
    <template>
      <input v-model="text" placeholder="Type here">
      <p>{{ text }}</p>
    </template>

What do we need to do to access the DOM directly?

  1. import { ref, onMounted } from 'vue'
  2. Declare a var a null ref: const pElementRef = ref(null) because the ref must be null as it will not exist until the component is mounted.
  3. In your element, use ref="pElementRef"
  4. In your onMounted callback function you can set the value initially. eg:
    onMounted( () => {
    pElementRef.value.textContent = 'mounted!';
});

<script setup>
    import { ref, onMounted } from 'vue'
    
    const pElementRef = ref(null)
    
    onMounted(() => {
      pElementRef.value.textContent = 'mounted!'
    })
    </script>
    
    <template>
      <p ref="pElementRef">Hello</p>
    </template>

const count = ref(0);

How do you pass params to a child component, which will not change:

In the child component, use defineProps. Then define the incomming variable in the child component.

<script setup>
    const props = defineProps({
        msg: String  // parent component has defined msg.  This lets child component know about the var.
    });
<script>
<template>
    <h2>{{ msg }}</h2>

You will be changing the msg in the child prop. The parent prop will use the updated msg. How do you make this happen?

  1. In the parent component, set the response from child component as: 
    <script setup>
    import ChildComponent from './ChildComponent.vue';

    const childMsg = ref('Hi from parent component');
</script>

<template>     
    <ChildComponent @response="(msg) => childMsg = msg" />
    <h2>childMsg</h2>
</template>
  2. In the child component, define an emitter, passing the value of 'response', the parent component's variable as follows:
    <script setup>
    const emit = defineEmits(['response'])  // parent components var name.

    emit('response', 'hello from child');
</script>

How are slots used in Vue?

  1. Just like <h2>, <div> - just pass in the data between the beginning element and end element. 
    <ChildComponent>This is the content of the slot for the child.</>
  2. In the child component, set the default of the slot, if there is any:
    <slot>Fallback content</slot>

    This way if no incoming content for the component, the Fallback content string will be printed where the slot exists.
